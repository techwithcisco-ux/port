# Market Stock Analytics — BranchPort

Standalone analytics dashboard that monitors all activity across the
BranchPort platform.

## What it shows

- **Platform Stats** — total users, businesses, products, revenue
- **User Directory** — all registered users, their data, items sold
- **Items Tracker** — every item on the market with prices and trends
- **Live Market Graph** — Binance-style ticker with sparklines and gainers/losers
- **Usage Analytics** — signups, active users, session data over time
- **Business Reports** — exportable CSV reports for official analytics

## How it connects to BranchPort

The market app is a read-only consumer of the BranchPort API:

1. **Sign in** — the admin password is verified server-side by
   `POST /platform/login` on the API (the `MARKET_ADMIN_PASS`
   environment variable). A successful login stores a 12-hour
   platform JWT in localStorage. When it expires, the app returns to
   the login gate.
2. **Load data** — `GET /platform/export` returns the full platform
   dataset (businesses, branches, products, sales, users) in one
   request, authorized by the platform JWT. The client caches it for
   10 seconds and re-fetches on demand.

No database credentials ever reach the browser — only the API URL:

```
VITE_API_URL=https://branchport-api.onrender.com
```

## Deployment (Render)

`render.yaml` at the repo root deploys this app as the
`branchport-market` static site, built with `VITE_BASE=/` and
`VITE_API_URL` pointed at the API automatically.

To deploy standalone instead: any static host works — build with
`VITE_BASE=/` and set `VITE_API_URL` to the API's public URL.

The admin password is generated by Render (`MARKET_ADMIN_PASS` on
branchport-api) — read it from the Render dashboard → Environment.

## Development

```bash
# From the repo root
npm install
npm run dev:market    # → localhost:5175

# Or from this directory
cd apps/market
npm install
npm run dev           # → localhost:5175
```

The API must be running (`npm run dev:api` from the repo root) and
`MARKET_ADMIN_PASS` must be set on it to sign in locally.

## Tech Stack

- React 18 + TypeScript + Vite
- Tailwind CSS (mobile-first)
- Recharts (live market charts)
- Raw `fetch` against the BranchPort REST API (platform JWT auth)
- Shared `@branchport/shared` types
